🐳 Deploy via Docker Terminal

Open the Terminal and run commands in order:

  1. Start core network: docker compose -f docker-compose.yml up -d
  2. Start gNB: docker compose -f docker-compose-gnb.yml up -d
  3. Start UE: docker compose -f docker-compose-ue.yml up -d

📋 Monitor Services

Check running containers: docker ps

Watch live status: watch docker compose -f docker-compose.yml ps -a

🖥️ Terminal Tips

Press Tab to autocomplete commands. Use ↑ / ↓ for history. Type ls to list files. Use vi docker-compose.yml to view the compose file (press :q + Enter to close).
